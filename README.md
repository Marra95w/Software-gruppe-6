# installasjon og kjøring

Prosjektet kjøres i Visual Studio Code.
1.	Start bakend 
    1.	Sjekk at du er tilkoblet skolens nett/VPN.
    2.	Åpne prosjektet i VS Code.
    3.	Gå til mappen scr.
    4.	Finn filen som heter Main.Java.
    5.	Åpne filen og trykk på Run.
    6.	Trykk på continue dersom dette alternativet vises. 
    7.	La backend kjøre. 
    8.	I terminalen vil det komme opp en kode det står RUN på. 
    9.	La backend kjøre ferdig.
2.	Start frontend
    1.	Finn mappen Frontend i VS Code.
    2.	Høyreklikk på mappen og velg Open in Integrated Terminal.
    3.	Pass på at det står frontend i terminalen 
    4.	Installer nødvendige avhengigheter:
                npm install
    5. Start frontend:
                npm run dev
    6.	Terminalen viser en lokal adresse under Local, på http://localhost:5173
    7.	Trykk på lenken for å åpne nettsiden i nettleseren.

Viktig informasjon 
•	Backend må kjøres før frontend.
•   Npm install må installeres før npm run dev
•	Begge må kjøre for at nettleseren skal fungere som forventet. 
•	Skolens internett/VPN må være tilkoblet for at informasjon skal kunne hentes fra databsen.
